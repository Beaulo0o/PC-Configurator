# Наброски интерфейса «Конфигуратор ПК»

Я подготовил предварительные наброски интерфейса настольного приложения. На этапе проектирования макет ещё будет уточняться.

## Главное окно

Главное окно приложения может содержать:

- панель навигации;
- каталог комплектующих;
- область текущей конфигурации;
- итоговую стоимость;
- ориентировочное энергопотребление;
- индикатор совместимости;
- элементы управления для сохранения и загрузки сборки.

## Каталог

Для компонентов каждой категории отображаются:

- название;
- производитель;
- основные технические характеристики;
- базовая цена каталога, используемая в расчёте сборки;
    - наличие внесённых розничных предложений;
- возможность добавить компонент в сборку.

Предусматриваются поиск и фильтрация.

## Конфигуратор

Предварительный перечень категорий:

1. Процессор.
2. Материнская плата.
3. Оперативная память.
4. Видеокарта.
5. Система охлаждения.
6. Накопитель.
7. Блок питания.
8. Корпус.
9. Дополнительные компоненты.

После изменения конфигурации система повторно выполняет проверки.

## Проверка совместимости

Ошибки и предупреждения должны отображаться раздельно.

Примеры:

- «Процессор несовместим с выбранной материнской платой: различаются сокеты».
- «Выбранный тип памяти не поддерживается материнской платой».
- «Мощности блока питания недостаточно для выбранной конфигурации».
- «Видеокарта превышает допустимую длину для выбранного корпуса».

## Стоимость

В нижней части окна конфигуратора отображаются:

- итоговая стоимость сборки по базовым ценам каталога;
- ориентировочное энергопотребление.

В карточке комплектующего при наличии данных рядом с базовой ценой отображаются розничные предложения и их источники, чтобы пользователь мог сравнить значения. Предложения не заменяют базовую цену, по которой рассчитывается сборка. Их вносит администратор через серверное приложение; автоматический сбор цен не планируется.

## Сохранённые сборки

В интерфейсе я предусмотрю следующие действия:

- создать сборку;
- переименовать её;
- открыть;
- изменить;
- удалить;
- посмотреть итоговые характеристики.

## Административная часть

Для администратора я планирую отдельное окно со следующими возможностями:

- добавление комплектующих;
- редактирование характеристик;
- изменение базовых цен;
- деактивация компонентов;
- управление категориями;
- просмотр источников цен и розничных предложений;
- внесение и обновление базовых цен и розничных предложений.
