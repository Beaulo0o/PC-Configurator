# Курсовой проект «Конфигуратор ПК»

В этой курсовой работе я разрабатываю проект системы для подбора комплектующих и формирования конфигураций персонального компьютера.

## Назначение системы

Я планирую, что приложение позволит собирать конфигурацию из каталога комплектующих, проверять совместимость выбранных компонентов, рассчитывать стоимость и основные характеристики сборки, а также сохранять пользовательские конфигурации.

В качестве основы я выбрал настольное клиент-серверное приложение: клиент и сервер будут разработаны на Python, а для хранения данных будет использоваться PostgreSQL. Основным интерфейсом станет настольное приложение.

В модели данных я предусматриваю базовую цену комплектующего для расчёта стоимости сборки и отдельные розничные предложения для сравнения. Цены и предложения в текущем проекте вносятся через серверное приложение; автоматический сбор цен не планируется.

## Основные возможности

- просмотр каталога комплектующих, поиск и фильтрация;
- формирование конфигурации ПК;
- проверка совместимости компонентов;
- расчёт стоимости и ориентировочного энергопотребления;
- проверка достаточности мощности блока питания и ограничений по корпусу и охлаждению;
- сохранение и редактирование пользовательских сборок;
- административное управление каталогом и централизованное обновление данных;
- сравнение базовой стоимости комплектующих с внесёнными в систему розничными предложениями.

Правила совместимости выполняются серверной логикой и не хранятся как универсальные записи в таблице. Сохранённые сборки содержат состав, а итоговая стоимость и энергопотребление рассчитываются по данным состава и комплектующих.

## Технологическая основа

- язык программирования: Python;
- система управления базами данных: PostgreSQL;
- архитектура: клиент-серверная;
- обмен данными: собственный протокол со структурированными сообщениями.
