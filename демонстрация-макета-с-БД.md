# Демонстрация работы макета системы с базой данных

Демонстрация является частью исследовательской части и показывает ожидаемую последовательность работы макета с PostgreSQL.

## Подготовка

1. Создать базу PostgreSQL и применить физическую схему.
2. Загрузить демонстрационный каталог.
3. Запустить сервер и клиент макета.
4. Проверить подключение клиента к серверу и сервера к базе данных.

## Сценарии

| Сценарий | Действия | Ожидаемый результат |
|---|---|---|
| Загрузка каталога | Пользователь открывает каталог | Отображаются активные комплектующие, характеристики и базовые цены |
| Совместимая сборка | Выбраны процессор, плата, память, накопитель и БП с совместимыми характеристиками | Ошибок нет, рассчитаны стоимость и энергопотребление |
| Разные сокеты | Выбраны процессор и плата с разными сокетами | Показана ошибка с названиями компонентов |
| Недостаточная мощность | Расчётная потребность превышает мощность БП с запасом 30 % | Показана ошибка и требуемая мощность |
| Сохранение | Сборка сохранена, закрыта и загружена повторно | Восстановлены состав, количества и актуальный статус проверки |
| Розничные предложения | Администратор внёс предложения для компонента | Показаны базовая цена, предложения и источники |
| Нет предложений | Для компонента предложения отсутствуют | Показана базовая цена и сообщение об отсутствии предложений |

Для итогового отчёта после запуска макета добавляются скриншоты основных сценариев с подписями рисунков.
